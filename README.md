## 它是怎么做到的 · 和别的生图工具不一样在哪

astra-imagen 的本事，是把一张图拆成**可自由组合的几层**，每一层都能单独换、叠加用——再交给 gpt-image-2 一次成图。

### 1. 六层模块，自由组合

| 层 | 是什么 | 怎么用 |
|---|---|---|
| **固有提示词** | 67 个手调的完整构图模板 | `--template 诗性编辑视觉` |
| **不同构图** | 100 种构图法 | `--comp S形构图` |
| **不同画师风格** | 383 位画家的视觉语言 | `--artist 莫奈,梵高` |
| **配色** | 736 个中国传统色 + 策展方案 | `--colors 黛蓝,朱砂红` |
| **风格片段** | 轻量可叠加的质感 | `--style 胶片暖调` |
| **人物垫图** | 真人多图综合、保脸放开 | `--person <名>` |

一行命令任意叠：


### 2. 它会按你的要求「现写提示词」

这是和别人最不一样的地方。astra-imagen 不只是套死模板——它内置了**母版（提示词写作配方）**：氛围类一套、重型编辑类一套。你给一个用途和一句话，它能照你的 spec **现写一条全新的、具体的提示词**，出图后还能把这条好提示词**存回库里**变成新模板。

### 3. 真任意比例，直接出图，零裁切

gpt-image-2 接受任意宽高（只要都能被 16 整除）。引擎按你要的比例算出精确尺寸**直接生成**——9:16、16:9、小红书、手机壁纸、X 封面，模型自己按整张画布排版，**不靠后期裁切**，边上的字和主体一个不丢。

### 4. 中文写得准

提示词点名要写的准确汉字，海报上的中文干净可读、不乱码。

### 5. 越用越厚的「复利库」

每条你创造的好提示词都能沉淀回库，模板、配色、构图、画师会随使用不断累积。**这是我们做这个技能的初衷——一个能自我沉淀、不断长本事的生图引擎；用它，去反哺它。**

## 100 种构图法

> 每一种都能 `--comp <名>` 注入，让模型按指定方式组织画面。

| 构图 | 用途 | 构图 | 用途 |
|---|---|---|---|
| `三分法构图` | 主体置于三分线或其交点 | `九宫格构图` | 井字分割，主体落在交点 |
| `黄金分割构图` | 主体落在黄金比例分割点 | `对称构图` | 左右或上下镜像对称，稳定庄重 |
| `非对称构图` | 不对称但视觉平衡，灵动 | `均衡式构图` | 不同元素重量相互制衡达到平衡 |
| `上下构图` | 画面分上下两部分 | `前后构图` | 前后景纵深分层 |
| `水平构图` | 强调横向水平线，平静开阔 | `垂直构图` | 强调竖向线条，挺拔高耸 |
| `三角形构图` | 元素构成三角形，稳定 | `倒三角构图` | 倒置三角，不稳定的张力 |

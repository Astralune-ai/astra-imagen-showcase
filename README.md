## 它是怎么做到的 · 两个核心能力

引擎 = 纯 CLI（Python 脚本）+ 一个 Markdown 提示词库。两个核心能力：

### ① 逆向工程：把别人的图反推成提示词（图 → prompt）

给一张你喜欢的图（别人的字效 / 海报 / 角色 / 设计），引擎按固定流程把它拆成一条**可复现、可迁移、能直接进库**的提示词。

**反推 → 验证 → 入库**

1. **反推** —— 八步拆解：文字内容 · 字体类型 · 字形结构 · 字效材质 · 颜色关系 · 光影空间 · 视觉气质 · 适合用途 → 产出【反推分析】+【可复制提示词】+【可替换模板（`{{变量}}`）】+【建议入库 front-matter】。
2. **验证** —— 用反推出的提示词调 gpt-image-2 出图，与原图比对（字形 / 字效 / 色 / 气质 / 版式），差距大改 1~2 轮重出。
3. **入库** —— 验证通过 → 存成一份 `prompt.md` 进库，从此可反复调用、换主题、换比例。

**版权红线**：游戏 / 品牌 / 他人 IP 角色 → 只反推「设计与版式系统」并迁移到**原创主体**（见画廊「角色海报 · 刊封编辑体」：从 LoL 角色海报反推版式，但出原创角色，不复刻原 IP）。

### ② Markdown 文档 → 生图规范（prompt.md 怎么写）

每个模板就是一份 `prompt.md`（Markdown + YAML front-matter）。引擎读它、填变量、调 gpt-image-2 出图——**任何人按这份规范写一份 `.md`，就能被引擎直接生成图**。

路径：`library/<类型>/<模板名>/prompt.md`

**Front-matter（文件头）**

| 字段 | 说明 |
|---|---|
| `name` | 模板名 |
| `type` | `poster-viz` / `text-poster` / `portrait` / `text2img` / `infographic` / `style-transfer` |
| `variables` | 变量名列表，如 `[主题, 比例]` |
| `optional` | 可留空的变量（不填自动补空、由模型自判） |
| `ratio` | 默认比例，如 `9:16`（命令行 `--ratio` 可覆盖） |
| `tags` · `note` · `category_kind` | 标签 · 一句话定位 · 氛围类/字体类/信息类 |

**Body（正文 = 提示词）**

- 正文就是喂给 gpt-image-2 的完整提示词，用 `{{变量}}` 占位（如 `{{主题}}`、`{{比例}}`）。
- `{{比例}}` 由 `--ratio` 自动填；`optional` 变量不填时自动补空。
- 含文字的模板，结尾钉一条 **【文字硬规则】**：核心文字须笔画 / 拼写准确、不乱码，风格化只施加在正确字形之上。

**调用**

```bash
imagen.py --template <名> --var 主题=企业AI落地 --ratio 9:16            # dry-run 报成本，不出图
imagen.py --template <名> --var 主题=企业AI落地 --ratio 9:16 --confirm   # 确认后才出图
```

叠加层：`--person <真人>`（多图垫脸、可多人）· `--ref <图>`（垫图 / 风格迁移）· `--artist` · `--colors` · `--comp` · `--style`。

### 其他

- **六层自由组合**：模板 · 构图(100) · 画师(383) · 配色(736 中国传统色) · 风格片段 · 真人垫图，一行命令任意叠。
- **任意比例零裁切**：gpt-image-2 接受任意宽高（宽高都能 ÷16），按比例精确直出、不靠后期裁切。
- **中文准**：提示词点名汉字，海报中文干净可读、不乱码。
